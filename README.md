# Smart Campus Complaint System

## 📌 Project Description
The Smart Campus Complaint System is a C programming project designed to manage campus complaints efficiently. Students can register complaints related to labs, hostels, transport, network, and other campus facilities. The system allows users to view, search, prioritize, and update complaint statuses.

## 🎯 Objectives
- To register campus complaints with unique complaint IDs.
- To categorize complaints based on their type.
- To prioritize complaints based on severity.
- To search and display complaints easily.
- To update complaint status.
- To generate a summary of complaints.

## ✨ Features
1. **Register Complaint** – Add a new complaint with its ID, category, problem, location, and priority.
2. **Display All Complaints** – View all registered complaints.
3. **Sort by Priority** – Display high-priority complaints first.
4. **Search Complaint** – Find a complaint using its ID.
5. **Update Complaint Status** – Change status to Pending, In Progress, or Resolved.
6. **Display Pending Complaints** – View complaints that are still pending.
7. **Generate Summary** – Display total complaints, priority counts, and status counts.

## 🛠️ Technologies Used
- Programming Language: C
- Compiler: GCC
- Code Editor: Code::Blocks
- Concepts: Structures, Arrays, Functions, Loops, Conditional Statements, and String Handling.

## ▶️ How to Run

1. Download or clone this repository.
2. Open the C source file in Code::Blocks or a text editor.
3. Compile the program using GCC:

   `gcc smart_campus.c -o smart_campus`

4. Run the program on Windows:

   `smart_campus.exe`
